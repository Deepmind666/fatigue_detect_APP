# 硬件指令清单（制作与功能）

> 重要：当前后端固件按“首字节即命令码”的旧规解析（无 `FF/FE` 边界）。若设备侧未升级到带边界的新协议，请使用下方“旧规（无边界）”格式。前端已支持两种模式切换。

## 旧规（无边界）制作指令
- 首字节：命令码（`0x01`=正常冰，`0x02`=去冰，`0x10`=热饮）
- 后续8字节：四通道重量/速度对（`W1 V1 W2 V2 W3 V3 W4 V4`）
- 无“总杯数/递减”补偿字段；固件当前忽略该扩展

示例：
- 茉莉雪芽 中杯 正常冰（水105，果175，水速0x78，果速0x73，通道1）：
  `01 69 78 AF 73 00 00 00 00`
- 茉莉雪芽 中杯 去冰：
  `02 69 78 AF 73 00 00 00 00`
- 柳橙百香 中杯 正常冰（通道2）：
  `01 B4 82 00 00 64 8C 00 00`

速度范围：`20..100`（固件示例提示），现场可按设备允许范围配置；通道未用则体积/速度为 `00`。

## 新规（带边界）制作指令
- 起始字节：`FF`
- 命令码：`01`（正常冰）、`02`（去冰）、`10`（热饮）
- 数据位（共9字节）：`W1 V1 W2 V2 W3 V3 W4 V4`（四通道的重量/速度对，`W1/V1`为水通道）
- 结束字节：`FE`

说明：热饮模式仅加果汁、不加水，因此水通道重量/速度固定为 `00`。果汁量与速度按配方与果汁通道映射到 `W2/V2`、`W3/V3` 或 `W4/V4`。

说明：补偿相关（总杯数/间隔/递减量）为前端内部逻辑，不随帧下发；指令帧仅包含上述9个数据位。

> 说明：体积范围为 `0x00..0xFF`；通道未使用则体积/速度填 `0x00`。速度（Vtop）范围为 `0..255`，现场建议值见下表；大杯体积按约 1.3× 放大并向下取整。`0x01=正常冰`，`0x02=去冰（先去皮后执行）`。

## 功能类指令（旧规 vs 新规）
旧规（无边界，首字节=命令）：
| 功能 | 指令 |
|---|---|
| 清洗开始（子命令） | `03 01 00 00 00` |
| 清洗停止（子命令） | `04 01 00 00 00` |
| 急停（独立指令） | `09 00 00 00 00` |
| 加水开始（子命令） | `03 02 00 00 00` |
| 加水停止（子命令） | `04 02 00 00 00` |
| 去皮（HX711 子命令） | `05 01 00 00 00` |
| 称重（HX711 子命令） | `05 02 00 00 00` |
| 标准校准（1000g，HX711 子命令） | `05 03 00 03 E8` |

新规（带边界，7字节）：
## 通用功能指令（7字节帧）
| 功能 | 指令帧 |
| 清洗开始（子命令） | `FF 03 01 00 00 00 FE` |
| 清洗停止（子命令） | `FF 04 01 00 00 00 FE` |
| 急停（独立指令） | `FF 09 00 00 00 00 FE` |
| 加水开始（子命令） | `FF 03 02 00 00 00 FE` |
| 加水停止（子命令） | `FF 04 02 00 00 00 FE` |
| 去皮（HX711 子命令） | `FF 05 01 00 00 00 FE` |
| 称重（HX711 子命令） | `FF 05 02 00 00 00 FE` |
| 继续制作 | `FF 07 00 00 00 00 FE` |
| 重新制作 | `FF 08 00 00 00 00 FE` |
| 标准校准（1000g，HX711 子命令） | `FF 05 03 00 03 E8 FE` |

> 校准字节顺序：Byte3 高字节，Byte4 低字节；若两字节均为 `0x00`，后端默认采用 `1000g`。旧规与新规的校准载荷顺序一致，仅是否带边界不同。
## 只出水（控制类子命令）
推荐使用控制类子命令开始/停止加水，与后端解析保持一致：

- 旧规：开始 `03 02 00 00 00`，停止 `04 02 00 00 00`
- 新规：开始 `FF 03 02 00 00 00 FE`，停止 `FF 04 02 00 00 00 FE`

若需按体积出水（仅兼容旧协议），可使用扩展制作帧，但不建议在当前版本使用。
